Who We Are

We are a team of four students working together to build a website as part of our DevOps group activity. We are learning web development, version control, and collaboration.

Our Mission

Our mission is to create a user-friendly website while improving our technical skills and learning how to manage projects using Git and GitHub.

What We Do

Web Development

Building simple and responsive web pages.

Git and GitHub

Tracking changes and collaborating on code.

Teamwork

Sharing responsibilities and reviewing code.

Our Workflow

We use branches to develop individual pages, commits to record our changes, and pull requests to review our work before merging it into the main project.
